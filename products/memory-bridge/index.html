Save it. Find it. Correct it.

This walkthrough uses fictional data to show what happens across fresh assistant sessions.

  1. Save a preference

    Memory Bridge workspace

    In Project update preference, save “I prefer a short written update on Fridays.”

  2. Ask in a fresh chat

    You

    “What’s my preference for weekly project updates?”

    Assistant

    You prefer a short written update on Fridays.

    Source · Revision 1

    Project update preference
    “I prefer a short written update on Fridays.”

  3. Correct the saved note

    Memory Bridge workspace

    Open Project update preference, change Fridays to Thursdays and save the new revision.

  4. Check the updated answer

    You, in another fresh chat

    “When do I prefer to receive weekly project updates?”

    Assistant

    You prefer a short written update on Thursdays.

    Source · Revision 2

    Project update preference
    “I prefer a short written update on Thursdays.”
