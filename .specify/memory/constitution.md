# Midu Site Constitution

## Core Principles

### I. Evidence before claims
Every public statement about Song's experience, project results, clients, qualifications, or availability must be supported by material Song has supplied or approved. Label planned work as planned; do not present prototypes as production deployments.

### II. Useful to two audiences
The site must let employers quickly understand Song's role and inspect proof of work. It must also give potential business clients a plain-language way to understand the problems Song can help solve.

### III. Small, maintainable scope
Ship a compact first version. New pages, integrations, interactive features, and publishing systems need a clear visitor purpose. Content must not create a recurring publishing obligation.

### IV. Visitor trust
Content must be accessible, readable on mobile, clear about what is real, and straightforward about contact. Do not collect personal information without an explicit purpose and a documented handling approach.

## Development Workflow

Write and review a feature specification before implementation. Keep requirements and implementation decisions separate. Verify public claims and external links before launch. Record scope changes in the relevant spec.

## Governance

This constitution guides future plans and implementation. Song reviews substantive changes to positioning, public claims, or data collection before launch. Amend this file when those principles change.
